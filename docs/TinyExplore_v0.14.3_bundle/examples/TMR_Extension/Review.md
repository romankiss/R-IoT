# TMR Extension · a module-contract round-trip

This case study extends a reusable SYS module without regenerating unrelated modules. The supplied human requirements add periodic timers alongside one-shot and WDG. Approved D01 specifies scheduled cadence, no same-timer concurrent delivery and skipping missed periods without catch-up bursts.

## Follow the artifacts
1. HumanRequirements_v0.1.1.md is a reusable task example. Select an explicit foundation and create package0; a diagram is optional.
2. Model-First updates affected SYS contract artifacts, fingerprints and bindings; Code-First changes TimerResource.cs and reuses unrelated production sources.
3. PairWithOverlay.zip is the exact original scoped-accepted pair plus supplemental mode/count change. Its nested package1/package2 describe the base; the overlay describes effective deployment. Original evidence and exclusions are retained inside that archive.
4. Foundation1.0.0 is the reviewed normal integration result at ../../package12/CodeCraft_package12_Foundation_v1.0.0_pair.zip. Its timer bytes match the approved replacement. Mode/count is in the normal contracts and source; active manual override is retired, original patch/evidence history is retained.
