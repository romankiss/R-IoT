# Agile module references

SYS, EMPTY and LORA Model-First contracts are read-only teaching/reference artifacts from the source pair declared by the catalog. An agile Module Contract comprises README.md, _at.json and _module.json. Runtime instances are composed via metadata bindings; type identity and instance suffix are distinct.

Use an explicitly selected complete package12 for generation. Do not mix a loose reference module with a different pair without validation. The separate SYS/EMPTY/SYS+EMPTY ZIPs under templates/model-first are derivation examples, not new runtime-verified pairs.
